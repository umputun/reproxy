# reproxy review profile

- **What it is**: an open-source edge HTTP(S) reverse proxy in Go (single binary and docker image).
  Self-hosters run it on the internet edge, in front of their services. Providers: static, file,
  docker, consul catalog. Optional RPC plugins, ACME certificates, management API.
- **What a real failure looks like**: a request routed to the wrong upstream, or to one the client
  chose; auth, IP allowlist or throttle bypassed; wrong or broken responses (headers, encoding,
  ranges, bodies); a crash, leak or hang under traffic; a config that worked and stops working after
  an upgrade.
- **Blast radius**: depends on which configs and routes a defect needs. Shared request-processing
  defects can affect multiple services; scope each finding to its triggering configs, routes and
  requests. Request
  input (Host, path, headers) is attacker-controlled. Operator config is trusted.
- **Who maintains it**: a solo maintainer. Fixes should be small and proportionate; no
  speculative abstraction.
- **Reporting bar**:
  - grade by demonstrated reachability and impact, not by category.
  - major and above: wrong routing, security on the request path, data or response corruption,
    race or leak in the hot path. A behavior change for existing configs is major only when it
    breaks a working setup unintentionally; an intentional security fix is not.
  - minor: an untested contract or a real regression risk (branch coverage alone is not a finding);
    docs that would lead an operator to a wrong config.
  - not worth reporting: style the linter already owns, hypotheticals that need a hostile operator
    config, cosmetic wording.
- **Deliberate conventions**:
  - all source under `app/`; `lib/` is the plugin library.
  - logging via `github.com/go-pkgz/lgr` with `[INFO]`/`[WARN]`/`[DEBUG]` prefixes.
  - mocks generated by moq, never hand-written; tests use testify, table-driven.
  - comments lowercase and only for a non-obvious reason; tests carry no comments except a
    regression test's one-line reason. Godoc is the exception: short, starts with the element's
    name, normal capitalization.
  - backward compatibility of existing rules and flags matters: new behavior is opt-in.
  - golangci-lint (`.golangci.yml`) must report 0 issues; README documents every operator option.
